# Mangools on GitHub

[Mangools](https://mangools.com) is an SEO toolkit: KWFinder, SERPChecker, SERPWatcher, LinkMiner, SiteProfiler and AI Search Watcher. The repositories here are for developers who want the same data in their own code, workflows and AI assistants.

## Mangools API

- [API documentation](https://apidocs.mangools.com) with a Try it panel on every endpoint
- [OpenAPI specification](https://github.com/mangools/api-spec), a mirror of https://api.mangools.com/v3/openapi.json
- [Python SDK](https://github.com/mangools/sdk-python): `pip install mangools`
- [TypeScript SDK](https://github.com/mangools/api-client-typescript): `npm install mangools-api-client`
- [Postman collection](https://www.postman.com/mangools-7057526/mangools-api), public workspace, ready to fork

## Automation and AI

- [n8n community node](https://github.com/mangools/n8n-nodes-mangools): `n8n-nodes-mangools`, 25 read-only operations. Tutorial with ready-made workflows: [apidocs.mangools.com/integrations/n8n](https://apidocs.mangools.com/integrations/n8n/)
- [Mangools MCP server](https://mangools.com/mcp): connect Claude, ChatGPT, Cursor, n8n and other AI clients to Mangools data
- [SEO skill for Claude](https://github.com/mangools/seo-skills): keyword research, competitor gap analysis and a prioritized content plan on live Mangools data

## Getting started

1. Sign in or [create a free account](https://mangools.com/users/sign_up).
2. Copy your API key at [mangools.com/api-token](https://mangools.com/api-token).
3. Send it in the `x-access-token` header. See [Authentication](https://apidocs.mangools.com/authentication).

Found a bug in an SDK or the spec? Open an issue in that repository. Everything else: [mangools.com/contact](https://mangools.com/contact).
